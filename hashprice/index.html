How the index is calculated.

One formula and four inputs, all from public Bitcoin chain data. The index is an estimate of what the network pays per unit of hashrate, not a forecast.

The inputs

144
The number of blocks the Bitcoin protocol targets in a day, one about every ten minutes.
Block subsidy
The new Bitcoin created with each block, set by the protocol and halved every 210,000 blocks. It has been 3.125 BTC since the halving of 20 April 2024.
Average fees per block
The transaction fees paid to miners, averaged per block.
Network hashrate
The computing power securing Bitcoin, estimated from the difficulty and the pace of recent blocks, in PH/s. One EH/s is 1,000 PH/s.
Bitcoin price
The price of one Bitcoin in US dollars.

Windows and updates

Live value
Subsidy and fees averaged over the last 144 blocks, about one day; the network hashrate as mempool.space estimates it over the last 1,008 blocks, about seven days; and the current Bitcoin price. Recalculated at most once a minute while this page is open.
Daily values
One value for each UTC day: that day's average reward per block, subsidy plus fees; mempool.space's hashrate estimate for that day; and the average of that day's Bitcoin prices. A day is added once it has closed. Where the price source has no point for a day, as in the earlier years when it is weekly, the price is interpolated between the nearest points either side.
Source
Public Bitcoin chain data and the Bitcoin price, read through the public API of mempool.space.

FAQs

All FAQs

What does the Omnes Hashprice Index measure?

It estimates what one petahash per second (1 PH/s) of Bitcoin hashrate earns in a day: the block subsidy and fees the network pays to miners, shared across the network's hashrate and valued at the Bitcoin price. It is quoted in US dollars per PH/s per day, and in Bitcoin per PH/s per day when the price is left out.

How is it calculated?

As 144 × (block subsidy + average fees per block) ÷ network hashrate in PH/s × Bitcoin price. The live value averages subsidy and fees over the last 144 blocks, and uses mempool.space's estimate of the network hashrate over the last 1,008 blocks, about seven days, with the current Bitcoin price.

Where does the data come from, and how often is it updated?

From public Bitcoin chain data and the Bitcoin price, read through the public API of mempool.space. The live value is recalculated at most once a minute while this page is open. The history holds one value for each UTC day, added once the day has closed, and can be downloaded as a CSV file.

How does it relate to the Omnes Mining Note?

Bitcoin paid in place of undelivered hashrate for the Omnes Mining Note is calculated using the Omnes Hashprice Index. Network figures are estimates from public chain data, not a forecast of what any note will pay.
